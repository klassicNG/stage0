# Profile Card

A simple responsive profile card built with HTML, CSS, and JavaScript.

# Features

- Semantic HTML structure using `<article>`, `<figure>`, `<section>`, and `<nav>`.
- Responsive layout for mobile, tablet, and desktop.
- Live current time displayed in milliseconds using `Date.now()`.
- Avatar image with alt text.
- Social links open in new tabs with safe attributes.
- Separate lists for hobbies and dislikes.

# How to Run

1. Clone or download the project.
2. Open `index.html` in your browser.
3. The card will display all required information and show the current time in milliseconds.
